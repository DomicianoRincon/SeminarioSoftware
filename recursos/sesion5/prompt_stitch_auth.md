# Prompt de Diseño para Google Stitch: Autenticación en `mi_app_1`

Usa este prompt en el lienzo de Google Stitch (`stitch.withgoogle.com`) para generar el diseño visual de las dos pantallas de acceso de la red profesional:

---

## Pantalla 1: Inicio de Sesión (`LoginScreen`)

```text
Diseña una pantalla móvil limpia y moderna de inicio de sesión para una red social profesional llamada "Conecta".
- Fondo claro y minimalista (#FBFBFD).
- Encabezado con el logotipo de la aplicación, el título "Bienvenido de nuevo" y un subtítulo invitando a ingresar con las credenciales profesionales.
- Campo de texto para Correo Electrónico con icono de sobre y texto de ayuda "tu.nombre@empresa.com".
- Campo de texto para Contraseña con icono de candado y ocultamiento de caracteres.
- Enlace en texto sutil "¿Olvidaste tu contraseña?".
- Botón principal prominente en color índigo (#4453C9) con texto blanco "Iniciar sesión".
- Divisor visual con texto "o continúa con".
- Botón secundario contorneado para "Acceder con Google".
- En la parte inferior, texto "¿No tienes una cuenta?" con enlace en negrita "Regístrate aquí".
```

---

## Pantalla 2: Registro de Usuario (`RegisterScreen`)

```text
Diseña una pantalla móvil de registro de nuevo usuario para la red social profesional "Conecta".
- Encabezado con botón de regreso, título "Crear cuenta" y subtítulo "Únete a la comunidad de profesionales".
- Campo de texto para Nombre Completo con icono de usuario.
- Campo de texto para Titular Profesional con icono de maletín y placeholder "Ej. Diseñador de Producto / Ingeniero de Software".
- Campo de texto para Correo Electrónico.
- Campo de texto para Contraseña y Confirmar Contraseña.
- Botón principal en color verde azulado (#0F8478) o índigo con texto blanco "Crear mi cuenta".
- Nota legal en texto pequeño sobre los términos del servicio y política de privacidad.
- En la parte inferior, enlace para "Iniciar sesión" si ya tiene cuenta.
```
